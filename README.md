# Budget Mobile App

This is a simple installable web app (PWA).

## What it does
- Records individual grocery, activity, gas, and other expenses
- Calculates weekly totals and remaining budget
- Records credit-card and line-of-credit payments
- Stores data locally on the phone/browser
- Exports all records to CSV

## How to publish
Upload all files in this folder to any static website host. The site must use HTTPS for the install/offline feature.

After opening the published site on your phone:
- iPhone Safari: Share > Add to Home Screen
- Android Chrome: menu > Install app / Add to Home Screen

Important: Data is stored only in that browser/device. Export CSV regularly as a backup.
